ADCAT DESKTOP · 1.3.1

第一次用，从这里开始。

用一个总控台调整音乐频谱、管理 Nexus 启动栏。按下面的步骤操作，先看到效果，再应用到桌面。

测试版说明：已完成交叉编译与独立逻辑测试；Windows 界面和真实 Nexus 联动仍待实机验证。

① 打开程序开机自启动② 调整频谱③ 关闭大字④ 撤销与恢复常见问题

01第一次打开

  1. 先把测试包完整解压，关闭已经打开的旧控制台。
  2. 双击 AdCDesktop.exe。这是控制台更新包，仍需原来安装好的 Rainmeter 和频谱皮肤。
  3. 如果出现目录选择框，选择原桌面工具的安装根目录，也就是里面能看到 Rainmeter 文件夹的那一层。不要选择 Rainmeter 文件夹内部，也不要选择这次下载的压缩包目录。
  4. 窗口标题为「AdCat 桌面」，上方有「音乐频谱」「Nexus 启动栏」两个页面。

音乐频谱

左侧看模拟预览、选配色；右侧调参数；底部应用到桌面。

Nexus 启动栏

上方启动或打开详细设置；下方管理悬停文字。

可以先在解压目录里试用新版。确认满意后，备份旧的 AdCDesktop.exe 和它的 .config 文件，再把新版这两个文件及 QuickStart.html 放进原安装目录的 SpectrumControl 文件夹。

频谱、Nexus，各自决定要不要自启动

窗口顶部有两个独立开关：「频谱 · 开机自启动」与「Nexus · 开机自启动」。

  1. 点击开关，绿色表示已登记自启动，灰色表示 AdCat 自启动关闭。开关立即保存，不用再点“应用到桌面”。
  2. 下次登录当前 Windows 账户时生效，不会立刻启动或退出程序，也不会自动打开总控台。
  3. 保存失败会显示原因并恢复读回的状态；未安装的组件不能开启。Nexus 路径可以在 Nexus 页面里选择。
这些开关只管理 AdCat 创建的启动项。若原程序里也开启过自启动，关闭 AdCat 开关后仍可能启动。页面会提示已识别的原程序自启动，点击“系统启动项”检查，或在 Rainmeter / Nexus 原生设置里关闭，避免重复启动。

频谱开关启动的是 Rainmeter，会恢复它已经保存的皮肤（包括可能启用的时钟）。如果希望登录后看到频谱，先勾选“显示频谱”并应用。

Windows 的启动应用设置可以覆盖登记状态。若开关显示“已登记”但登录后未启动，请点“系统启动项”检查是否被禁用。移动或删除安装目录前，先关闭对应自启动开关；移动后重新设置。无需管理员权限。

02做出自己喜欢的频谱

选配色 → 拖动滑块 → 看预览 → 应用到桌面

  1. 点击「音乐频谱」，从左侧选择一个配色，例如「冰川蓝」。
  2. 拖动右侧滑块。左侧会预览样式变化；也可以直接输入数值后按回车。
  3. 勾选「显示频谱」。需要放在屏幕中间时，点击「水平居中」；需要放在启动栏附近时，点击「应用栏上方」后再微调 X、Y。
  4. 点击右下角「应用到桌面」，播放音乐，观察实际效果。
  5. 满意后点击「保存我的方案」，以后可以通过「读取我的方案」找回。
参数怎样理解
频谱宽度 / 波动高度控制横向长度与波动范围。太挡画面就调小。
声音灵敏度数值越高，小声音也更容易让频谱起伏。
回落平滑度数值越高，声音减弱后回落越慢；0 表示不增加回落延迟。
不透明度100% 最明显，0% 完全透明。
X / Y在主屏幕常见布局中，X 越大越靠右，Y 越大越靠下。
鼠标穿透点击可穿过频谱。开启时，下面的鼠标悬停效果不可用。

不知从哪里调起，可先试：宽度 700、高度 60、灵敏度 45、平滑度 150、不透明度 70%，再按自己的屏幕调整。

预览采用模拟音源，不采集系统音乐。它用来比较参数和配色，实际桌面波形以 Rainmeter 为准。「暂停动画」只暂停预览；「模拟静音」只演示回落，都不会暂停你的音乐或关闭桌面频谱。

「读取我的方案」只把参数载入面板，仍需点击「应用到桌面」。切到 Nexus 页面不会丢掉尚未应用的频谱修改。

03关闭鼠标碰到图标就弹出的字

有两种文字：立即出现的图标名称，以及停留一会儿出现的信息气泡。要完全清爽，两种都关闭。

  1. 点击「Nexus 启动栏」。未找到程序时，点击「选择 Nexus.exe」，找到已经安装的 Nexus 程序。
  2. 从 Nexus 图标的右键菜单退出 Nexus。不要只关闭它的设置窗口。
  3. 回到总控台点击「重新读取」，再点击「关闭所有悬停文字」。
  4. 看到「文字设置已保存并校验」后，点击「启动 Nexus」。
  5. 把鼠标移到多个图标上，并停留几秒，检查图标名称和延迟气泡是否都消失。
退出后再应用，是为了避免 Nexus 在退出时把旧配置写回来。第一次应用会自动保存原文字设置，后面可以恢复。

如果只想保留一种文字

分别勾选或取消「显示悬停图标名称」「显示延迟信息气泡」，然后点击「应用文字设置」。同样需要先退出 Nexus，应用后再启动。

如果按钮不可用，或想改成小字

点击「打开 Nexus 详细设置」。它会打开 Nexus 自己的设置窗口。不同版本配置不兼容时，总控台会禁止自动修改，可用原生设置完成：

想做什么Nexus 原生设置路径
关闭图标名称外观 / Appearance → 取消「鼠标经过时显示图标标签」。
关闭信息气泡行为 / Behavior → 更多选项 / More Options → 气泡提示选「从不 / Never」。
保留但缩小文字外观 → 标签设置 / Label Settings → 调小字体，按喜好关闭背景和描边，再保存。

若详细设置没打开，点击 Dock 上的 Nexus 控制图标，或尝试默认快捷键 Ctrl+F11。仅安装频谱的用户可以直接使用频谱页面，不必安装 Nexus。

04改错了，怎样恢复？

遇到的情况使用哪个按钮
频谱还没应用，想丢弃本次修改音乐频谱 →「重新读取」，重新载入已保存的桌面配置。
想回到自己保存的频谱方案「读取我的方案」→「应用到桌面」。
想恢复首次应用前的频谱设置音乐频谱 →「恢复原设置」。没有备份时按钮不可用。
想重新显示原来的 Nexus 文字先退出 Nexus →「恢复原文字设置」→「启动 Nexus」。
想恢复整套桌面外观使用原安装目录的 Restore-Desktop.cmd；频谱页面的恢复按钮只负责频谱。

Nexus 的恢复只合并仍存在的文字设置，不把整套 Dock 配置换回旧版本。频谱方案和 Nexus 文字备份是分开的。

遇到问题，先看这几项

预览在动，但桌面没有频谱？

先检查「显示频谱」是否勾选、不透明度是否大于 0，再点击「应用到桌面」并播放音乐。若顶部显示组件未运行，点击「启动组件」。检查 X、Y 是否把频谱移到了屏幕之外。

选择了目录仍提示找不到配置？

选择原安装根目录。它至少应包含 Rainmeter/Rainmeter.ini 及原来的 Skins/RetrOcOlOr 皮肤。这个测试包不包含第三方软件和皮肤；首次安装应使用源码包中的 Install.cmd。

为什么 Nexus 的“关闭所有悬停文字”是灰色？

总控台没有识别到完整、兼容的文字配置。先启动 Nexus，保存一次设置，退出后重新读取。仍不可用就按上面的原生设置路径操作。

动画会一直耗资源吗？

按钮反馈与切页动画都是短暂过渡。系统关闭界面动画时，总控台也会减少这些动效；频谱预览会复用背景网格和曲线对象。

切到 Nexus 页面，预览是不是停了？

是的。切页或最小化时会暂停预览动画；回到频谱页面后继续，减少不必要的后台绘制。

保存方案和应用到桌面有什么不同？

保存方案是留一份参数；应用到桌面才会修改实际频谱。保存后不会自动应用。
