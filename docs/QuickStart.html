ADCAT DESKTOP · 1.3.3

第一次用，从这里开始。

AdCat 桌面把音乐频谱、桌面时钟和 Nexus 启动栏放在一个总控台里。下载、安装、调位置，几分钟就能用上。

1.3.3 正式版 · Windows 11

① 安装 ② 打开总控台 ③ 调整频谱与位置 ④ 开机自启动 ⑤ Nexus 设置 ⑥ Nexus 外观 ⑦ 恢复原桌面 常见问题

01安装：一个 EXE，双击即可

  1. 从 GitHub Releases 下载 AdCat-Desktop-Setup-1.3.3.exe。
  2. 双击运行，不需要解压。
  3. Nexus 官方安装器弹出 Windows 管理员提示时，点“是”。
  4. 安装完成后会自动隐藏桌面图标、自动隐藏任务栏，并启动 Nexus 和频谱。

会自动完成

下载/校验 Rainmeter、时钟和频谱皮肤、Nexus；构建 AdCat 控制台；创建桌面快捷方式；启动组件。

桌面快捷方式

AdCat 桌面打开总控台；启动 AdCat 桌面重新启动 Nexus/频谱；恢复原桌面还原安装前状态。

SmartScreen：EXE 没有购买商业代码签名。如果提示“已保护你的电脑”，点“更多信息 → 仍要运行”。
只更新已有安装：下载 AdCat-ControlCenter-1.3.3.0.zip，解压后运行 Install.cmd，选择原来的安装根目录。它会更新控制台、恢复脚本和快捷方式名称，不需要重装 Rainmeter/Nexus。

02打开总控台

双击桌面的 AdCat 桌面。窗口顶部是频谱/Nexus 自启动开关和状态；下面分为音乐频谱、Nexus 启动栏和 Nexus 外观三个页面。

音乐频谱

左侧预览配色和波形；右侧调宽度、高度、灵敏度、颜色、位置；底部应用到桌面。

Nexus 启动栏

检测 Nexus 路径、启动程序、打开原生设置，以及关闭鼠标悬停文字。

右上角始终有 恢复原桌面 按钮；这是比“恢复原设置”更彻底的还原入口。

第一次打开如果选择目录，请选择包含 Rainmeter 文件夹的安装根目录，而不是 Rainmeter 文件夹内部。

03调整频谱，并直接拖动位置

选配色 → 拖滑块 → 拖动迷你桌面里的频谱条 → 应用到桌面

  1. 进入 音乐频谱，在“色彩灵感”里选一个配色，例如“冰川蓝”。
  2. 拖动宽度、波动高度、灵敏度、平滑度、不透明度；左侧预览会同步变化。
  3. 在 位置与显示 里，找到迷你桌面预览。直接拖动绿色频谱条，X/Y 输入框会同步更新，范围自动限制在屏幕内。
  4. 也可以点“水平居中”“应用栏上方”，或直接输入 X/Y。
  5. 勾选“显示频谱”，点击右下角 应用到桌面。播放音乐观察实际效果。
参数怎么理解
频谱宽度 / 波动高度控制横向长度和波动范围。挡住画面就调小。
声音灵敏度数值越高，小声音也更容易触发波动。
回落平滑度数值越高，声音停止后回落越慢；0 表示不额外延迟。
不透明度100% 最明显，0% 完全透明。
X / YX 越大越靠右，Y 越大越靠下。直接拖预览条最快。
鼠标穿透点击可穿过频谱。开启时，悬停效果不可用。
预览使用模拟音源，用来比较参数；实际桌面波形由 Rainmeter 提供。“暂停动画”和“模拟静音”不会关闭桌面频谱。

调好后可以点“保存我的方案”；以后用“读取我的方案”找回，仍需点“应用到桌面”才真正生效。

04决定要不要开机自启动

窗口顶部有两个独立开关：频谱 · 开机自启动 与 Nexus · 开机自启动。

  1. 点击开关，绿色表示已登记，灰色表示关闭；修改立即保存。
  2. 下次登录 Windows 当前账户时生效，不会立刻启动或退出程序。
  3. 如果原程序自己也设置了自启动，页面会提示；可在“系统启动项”或原程序设置里关闭，避免重复。

移动或删除安装目录前，先关闭对应自启动开关；移动后重新设置。此功能不需要管理员权限。

05让 Nexus 更清爽

如果鼠标碰到 Dock 图标时弹出文字，可以关闭。这里有两种文字：图标名称和延迟信息气泡。

  1. 点击 Nexus 启动栏。如果未找到程序，点“选择 Nexus.exe”。
  2. 从 Nexus 图标右键菜单退出 Nexus，不要只关闭设置窗口。
  3. 回到 AdCat 点 重新读取，再点 关闭所有悬停文字。
  4. 看到“文字设置已保存并校验”后，点 启动 Nexus。
  5. 把鼠标移到多个图标上并停留几秒，确认名称和气泡都消失。
第一次修改会备份原文字设置，可点“恢复原文字设置”。如果总控台无法识别你的 Nexus 配置，请使用“打开 Nexus 详细设置”手动调整。

Nexus 不出现？

先看 AdCat 桌面 → Nexus 启动栏 是否检测到 Nexus.exe；有路径就点“启动 Nexus”。如果 Dock 被隐藏，右键系统托盘的 Nexus 图标 → Dock → Show Dock。安装阶段必须允许 Nexus 的管理员确认，否则不会安装。

06一键换 Nexus 外观

顶部导航新增 Nexus 外观 页。这里不需要打开 Nexus 首选项，也不会改图标和顺序。

极简底部

42px 图标、轻反射、小间距；Dock 安静地待在底部。

均衡默认

49px 图标、中等反射与放大；接近 Nexus 默认的稳重效果。

大图标展示

60px 大图标、强反射与明显放大；适合展示和演示。

紧凑悬浮

36px 小图标、低反射、小间距；适合屏幕空间紧张。

雨滴玻璃

40px 图标、明显反射、雨滴和水波；最有氛围的一套。

  1. 点顶部 Nexus 外观，每张卡片都有桌面效果预览图。
  2. 点对应卡片的“应用”。AdCat 会先退出 Nexus、写入参数，再自动启动。
  3. 看 Dock 效果；不满意就点“恢复原外观”，回到首次应用前的参数。
首次应用会把原始外观备份到 SpectrumControl/Backups/nexus-appearance-original.json。应用过程中 Nexus 会重启一次，这是正常现象。

07恢复原桌面

控制台右上角的 恢复原桌面 会先确认，然后：

  1. 停止 Nexus 和频谱/Rainmeter。
  2. 强制显示桌面图标和任务栏，不再沿用备份里的“隐藏图标”状态。
  3. 恢复安装前的壁纸设置。
  4. 控制台保持打开，并提示恢复结果。
桌面快捷方式 恢复原桌面 也会执行同样的恢复。旧版升级后如果快捷方式名称没变，运行一次新的控制台更新包即可清理旧 ADC 快捷方式。
想恢复什么用哪个入口
频谱还没应用，丢弃本次修改音乐频谱 →“重新读取”
回到保存过的频谱方案“读取我的方案” → “应用到桌面”
回到首次应用前的频谱设置“恢复原设置”（仅频谱）
整套桌面图标/任务栏/壁纸右上角“恢复原桌面”或桌面快捷方式

遇到问题，先看这几项

恢复后桌面软件图标还是不出现？

请确认用的是 1.3.3 或更新版本，并点击右上角 恢复原桌面。1.3.3 会强制显示图标和任务栏；旧版只更新控制台时恢复脚本可能还是旧的，需要运行 AdCat-ControlCenter-1.3.3.0.zip 里的 Install.cmd。

Nexus 没出现？

检查安装时是否在管理员提示中点“是”；打开“Nexus 启动栏”看路径；有路径就启动 Nexus，Dock 隐藏时从托盘菜单选 Show Dock。已有 Nexus 配置会被保留，不会覆盖。

安装时提示需要管理员权限或 Error 5？

这是 Nexus 官方安装器的 Windows 权限提示。请允许管理员权限后重试；如果之前取消过，重新运行安装包。不要删除已有 Nexus 配置。

提示 An installation directory is required？

这是旧版启动脚本的问题。1.3.3 已修复；已有安装可运行修复包，或直接用新的 AdCat-Desktop-Setup-1.3.3.exe。

位置拖到屏幕外了？

在迷你桌面里把频谱条拖回可见区域，或直接输入 X/Y，再点“应用到桌面”。坐标会自动限制在屏幕范围内。

预览在动，桌面没反应？

确认“显示频谱”已勾选、不透明度大于 0，点了“应用到桌面”，并且顶部状态显示频谱运行。若组件未运行，点“启动组件”或桌面上的“启动 AdCat 桌面”。
